开发足迹和心路历程

本站从 2026 年 7 月 22 日的一个念头开始，到功能完整的个人博客，历时约 80 天

这不是教程，而是一份真实的开发日志，记录我的开发体验

第一阶段：从零到一（7.22 - 8.14）

目标：让博客能跑起来

动作：搭建 Hugo 环境 → 选定 Stack 主题 → 跑通最小模型 → 处理版本差异

收获：先跑通最小模型，再回头补理论。选对主题和教程比盲目照抄更重要

关键节点：

  • 7.22 决定搭建静态博客
  • 7.23 跑通 Hugo 最小可执行模型
  • 7.29 选择 Stack 主题，踩坑：教程版本与实际版本脱节

    参考大佬的博客：莱特雷-letere。

  • 7.30: 安装 Stack 主题后构建报错

    在 AI 辅助下根据错误信息，定位出问题的代码，修改后成功构建

  • 8.14 实现源码与静态页面分仓管理

第二阶段：功能搭建（8.15 - 9.13）

目标：让博客可用、可看

动作：选择参考教程 → 移植功能 → 记录问题 → 本地测试通过 → 上传 GitHub 仓库

收获：美化和测试需要时间，但每一步都能看到变化

关键节点：

  • 8.7 发布第一篇文章
  • 8.16 增加评论功能
  • 8.25 引入浏览量统计
  • 9.9 美化文章列表和正文图片的圆角与悬停动画

    排查思路：定位元素DOM层级 → 复制选择器 → 本地测试css属性 → 覆盖原样式

  • 9.13 增加右侧栏归档、分类悬停缩放动效；清理测试文件，修正工作流构建命令

    排查思路：run hugo -D → run hugo，避免草稿泄露和工作流卡住

第三阶段：深度美化与细节打磨（9.21 - 10.18）

目标：让博客从“能用”变成“好用、好看”，深度还原参考博客外观样式

动作：学习 HTML/CSS 基础 → 用开发者工具定位样式 → 逐条覆盖主题默认样式 → 修复历史遗留 Bug → 总结成可复用的 SOP

收获：曾经无法解决的问题，现在大多是 CSS 属性的问题。开发者工具是排查问题的神器

关键节点：

  • 9.21 至 10.2：学习 HTML/CSS 基础，整理笔记，为深度美化做理论储备
  • 10.6 页脚增加运行时间、文章统计和访问量；修复时钟不居中；修改部分注释

    排查思路：登录 vercount 后台配置站点 ID 信息；时钟居中实际上是 css 属性问题

  • 10.8 美化菜单和全局滚动条；引入飞鱼页脚；返回顶部图标悬停旋转；修复动态背景半屏问题；修复时钟亮暗主题变色问题

    排查思路：参考大佬博客 → 定位 DOM 层级 → 新建样式规则 → 测试通过后写入 .scss

  • 10.10 浏览量图标移至页脚并统一风格；返回顶部图标适配暗色主题；调整页脚布局；更新友链
  • 10.18 更新“对象复用”文章内容、排版，新增封面；归档页新增“Python”分类页面和标识；新增主页动态公告；优化其他细节

第四阶段：平稳运行与内容沉淀（10.19 - 至今）

状态：从重度开发转向日常维护与内容输出

关键节点：

  • 10.19：总结、沉淀，开始写下年度复盘长文
  • 10.20：开始投递简历，将博客作为核心作品对外展示
  • 10.23：跑通第一个 Flask API 接口，正式开启后端探索
  • 10.25：用时 5 天、耗尽了上万字废稿，浓缩而成的 3900 字心路历程《转行一周年：从 Hello World 到求职市场》
  • 10.26：重构 Hugo 分类系统，修复 URL 编码冲突与双生页面问题；抽离首页公告模块，实现数据与视图分离

收获：我意识到，最好的输入是输出。博客不再只是我的“作业”，它已经成为了我与真实世界交互的底气。

提交记录和开发体验

七月：探索与试错

  • 2026-07-22: 决定搭建静态博客

    筛选 AI 给的建议，结合“深度思考”的和“问题导向”的学习风格，决定用小白友好、轻量静态博客展示学习成果

  • 2026-07-23: 跑通最小可执行模型

    用 Hugo + 默认主题，走完“构建 → 发布 post”的最小流程

  • 2026-07-25: 选择一款高二次元风格的博客主题

    本地根目录命名为 test，选了合眼缘的二次元主题，但构建完就不知道下一步做什么了

  • 2026-07-26: 踩坑：教程太多，质量参差

    找到 Stack 主题的视频教程，但每个 up 主操作不同，对小白不友好；最后找到一个手把手教学的视频

  • 2026-07-27: 万事开头难，先从 GitHub 入门开始

    放弃长教程，从短教程入手。浏览 GitHub 入门，更新个人档案，逛逛 Topics 和 awesome list

  • 2026-07-28: 看视频学习如何自动部署

    看懂六七成，边操作边理解。直接用民间改良版工作流文件，不硬啃官方文档

  • 2026-07-29: 选择 Stack 主题，踩坑：教程版本与实际版本脱节

    创建 dev/ 测试主题，发现教程与当前版本差异大，无法一比一照抄，需要自己熟悉配置文件

  • 2026-07-30: 安装 Stack 主题后构建报错

    在 AI 辅助下处理 command error: failed to load modules，发现 [[module.imports]] 的 path 指向失效，改为 path = "hugo-theme-stack" 后成功构建

八月：正式构建
