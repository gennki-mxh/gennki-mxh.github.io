对象复用的介绍及其分类

什么是对象复用

  • 定位：“对象复用”属于Python运行时的策略，是一种高层设计思路
  • 作用：对于某些不可变对象(int,float,str,tuple…)，如果值相同，就重复使用而非新建
  • 根本依据：对象的不可变性。只有不可变对象才能安全复用

对象复用的实现方法，按触发方式分类

  • 编译时自动(不可依赖，仅作了解)：常量折叠
  • 运行时自动(CPython中可依赖)：小整数缓存，标识符字符串自动驻留
  • 显式手动(程序员手动)：sys.intern()，强制驻留字符串

关于常量折叠

什么是常量折叠(Constant Folding)

  • 定位：常量折叠是一项编译优化技术，在编译时发挥作用
  • 作用：计算常量表达式(如2+3→5)，并复用相同的字面量对象(如a=257，b=257可能指向同一对象)
  • 依赖：常量折叠依赖于编译单元划分，而编译单元划分依赖于CPython的调用方式(运行脚本或交互模式)
  • 作用域：同一代码块(类、函数、模块顶层、交互式单行语句…)
  • 保证性：不可靠。编译器不需要保证常量折叠的结果，因为它属于“优化技术”而非“语言规范”
  • 引用池：常量表(Constant Table)，存在于每个代码块中，存放该代码块所有用到的字面量

编译器可自由选择

  • 是否做常量折叠
  • 在多大范围内做(同一行，同一语句，同一函数，同一模块)
  • 是否对字面量进行复用

举例说明常量折叠

声明一下，所有的例子均在同一模块内，通过VSCode调用同一个CPython(3.13)

例1，计算常量表达式

a = 2+3
b = 5

a = 666+999

例2，复用相同字面量对象

对于不在小整数范围（-5~256）内的整数，由模块级常量表持有它们的引用并复用

a = 999
b = 999
print(a is b)  # True，big_int

对于浮点数，其引用同样被模块级常量表所持有并复用

1

a = 1.1
b = 1.1
print(a is b)  # True，float

对于非标识字符串，同上

1

3

a = 'hello world'  # 带空格，非标识符字符串
b = 'hello world'
print(a is b)  # True，str

对于tuple，同上

b = (1,[1,1])

    b = 999

小结：

  • 在CPython中，模块级常量表串联所有类和函数内部的常量表，它们内部字面量引用均来源于模块级常量表
  • 对于例2、例3、例4，常量折叠复用字面量相同的对象，严格来讲这叫“常量去重”(constant deduplication)，或字面量复用，它经常和常量折叠同时发生，两者都是优化技术，但二者并不完全等同。

模块常量表与代码块常量池的关系

  • 疑问：既然模块常量表收集所有字面量，为什么还要设计代码块常量池？为什么要区分代码块？
  • 解释：为了支持局部作用域、闭包、函数对象的独立性，同时共享常量避免重复。每个代码块(函数、类)有自己的作用域和局部变量表，在编译时生成代码对象，常量池就是代码对象的一部分，用于存储该代码块内使用的常量索引。虽然实际对象共享引用，但每个代码块需要记录“我用到了模块常量表中的第几个常量”。这种设计节省内存，同时保持代码块的独立性

关于小整数缓存

什么是小整数缓存(Small Integer Cache)

  • 定位：小整数缓存是一项优化技术，是CPython的实现细节，不是语言规范强制要求的
  • 作用：-5到256的整数对象随CPython启动而创建，当代码使用了它们，Python直接返回缓存中的对象，而非新建
  • 作用域：全局
  • 保证性：可靠，CPython提供实现承诺，在CPython中可放心依赖，但在其他Python实现里可能不保证
  • 引用池：小整数缓存池，存放-5到256的整数对象

举例说明小整数缓存

  • 代码如下：
1
2
3
4
5
6
7

a = -5
b = -5
print(a is b)  # True，small_int

a = 256
b = 256
print(a is b)  # True

为什么小整数缓存采用预分配策略

  • 一方面是小整数具有极高的使用率，在解释器启动时提前创建，开销小且复用率高，可以通过print(sys.getrefcount())来查看小整数的引用计数，会得到一个庞大的数值，极高的引用计数往往意味着极高的使用率
  • 另一方面是小整数的数量少且固定，利用静态数组整合它们，能最大限度节约内存并降低复用难度
  • 演示代码如下：
1
2
3

import sys

print(sys.getrefcount(1))

关于字符串驻留

什么是字符串驻留(String Interning)

  • 定位：字符串驻留是一项优化技术，也是CPython的实现细节
  • 作用：首次使用时将字符串对象存入全局字典，后续相同字符串则复用同一对象
  • 作用域：全局
  • 保证性：部分可靠，标识符字符串可自动驻留，非标识符字符串则依赖于CPython实现细节，也可显式强制驻留
  • 引用池：字符串驻留池(Intern Pool)，是一个全局字典，可通过sys.intern()强制加入

举例说明字符串驻留的应用

代码如下：

1
2
3
4

import sys

a = 'hello_world'  # 标识符字符串
b = 'hello_world'
c = sys.intern('hello_world')
print(a is b)  # True
print(a is c)  # True
print(b is c)  # True

可以通过下面的代码到a、b、c在当前模块的全局命名空间里均绑定变量，但这已经是运行时的变量绑定，不是编译时的常量表(存在于代码对象的co_consts中)。

1
2
3
4

import sys
import __main__

print(sys.modules['__main__'].__dict__)

模块本身是全局命名空间的容器，其代码对象是隐式的，没有直接暴露为属性(Attribute)，也就没有类似于函数、类、方法等可执行体才会有的__code__属性

1
2
3

import __main__

print(__main__.__code__)  # 会报错

为什么字符串驻留采用“懒加载”策略

  • 因为字符串数量无限，且编译器无法预知什么样的字符串更常用，所以无法像小整数那样提前创先，无法实现预分配

关于常量去重

常量折叠与常量去重的精细区分

常量去重是编译器的行为，对象复用是这一行为导致的结果。常量去重和常量折叠发生在编译时，对象复用发生在运行时

区分如下：

  • 常量折叠：对表达式求值（如 2+3→5），产生新的常量值，目的是减少计算量
  • 常量去重：对于相同字面量，只存一份，目的是减少常量表条目
  • 对象复用：使运行时的多个变量、表达式结果指向同一个对象（来自常量表或缓存池），目的是共享内存中同一个对象

注意：运行时的复用（小整数缓存、字符串驻留），它们的作用独立于常量去重

举个方便理解的栗子

代码如下：

1
2
3
4
5
6

a = 2+3  # 常量折叠，产生5，然后去重
b = 5  # 常量去重
c = 5  # 常量去重
print(a is b)  # True，对象复用，a和b指向同一对象
print(b is c)  # True，对象复用
print(a is c)  # True，对象复用

说明：

  • 这里的2、3、5都是小整数，体现的是小整数缓存的复用效果，换成其他整数（如666、999）或浮点数，那么常量折叠、常量去重和对象复用的效果依然存在

  • 编译时发生了常量折叠和常量去重后，常量表条目就只保存一个对象5，运行时的三个变量a、b、c进行了is比较，那么这个5就发生了复用，使得这三个变量共享同一个对象。把这个整数对象换成其他类型的对象，结论依然成立
