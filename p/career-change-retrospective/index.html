转行一周年：从 Hello World 到求职市场

昨天和今天看似没什么两样，但去年和今年却完全是两个世界

2026-10-19 阅读时长: 8 分钟 3669 字

摘要

这是一篇记录我从化工厂辞职、历经大半年焦虑迷茫，用 10 个月时间从零自学编程，最终搭建出个人博客并成功投出简历的复盘。记录了我对高敏感人格、完美主义与问题导向学习法的思考和实践。

引言：致那个敲下 print('Hello World') 的夜晚

未来会是什么样子的？未来的我在做什么呢？我不知道。那我能想象一下吗？当然。当我安装好 Python，在 VSCode 里敲下第一行代码 print('Hello World')，我看到一个暗色调绚烂的赛博世界——映入眼帘的是一个巨大的 Hello World 金黄色雕像，抬头望向空中看到悬浮着无数个 Hello World 字符，它们化作数据流生成了这里的建筑物、飞行器和人类。这些字符在他们身上流动着，像条蜿蜒灵活的蛇一样，散发着浅绿色流光。未来的世界，会是一个数据化的世界吗？人类的行为会被数据化吗？一切皆可数据化吗？一晃半个小时过去了。不管怎样，当时的那个自己，一定是抱着极大的决心，才按下了回车键。

我想对自己说，焦虑、迷茫、麻木、逃避都是暂时的，我不会一直这样。有一种“静止”，叫初始化。我开始意识到，设想的最坏情况并没有发生，我的手脚并没有被完全锁死，因为我还能活动，还能思考、记录和幻想。渐渐地，我的情绪开始平复。我决定重新学习编程，因为它成本低，近在咫尺。

我不知道明天会发生什么，也想象不出一年后的光景是什么样的。我只是做好手上的事，却意外发现脚下的路竟然不断在往前延伸，就好像玩 Minecraft 一样——随着我不断往前走，越来越多的区块不断生成、刷新，我对这片区域也愈发熟悉。昨天和今天看似没什么两样，但是去年和今年却完全不同。一年前的今天，我刚敲下 print('Hello world')，一年后的今天，我把简历投向了真实的求职市场，向这个世界发出“我准备好了”的信号，去倾听来自现实世界的回响。

至暗时刻：从化工厂到窗边的背影

大学毕业后，我因为迷茫、毫无方向，看着周围的人陆续找到工作，倍感焦虑的我仓促之下选择一家化工厂的工作。这两个月里，我原以为我会感到安心，却没想到内心的拷问一直都在。某天身心俱疲的我躺在床上，再次面对内心的拷问：“不做这个，你还能做什么”。我没有回应，只知道我想要离开这里。

在化工厂工作了两个月便辞职回家休养。在家中独处的日子里，我度过了一段极其混乱、迷茫、焦虑、浑浑噩噩的时期。我见过自己无所事事、虚度光阴的模样。我不知道自己身上究竟发生了什么，也不知道自己为什么会这样，甚至质问命运不公，为什么是我？为什么要我经历这些？

我时常站在窗边望着远方，深陷那种“不知道自己能做什么”的泥沼感。我几乎每天除了吃饭睡觉上厕所，就在刷视频玩游戏看番。我曾尝试看书，却总是看不下去，费尽力气读完一本书，却难解心里的迷茫与痛苦。我经常控制不住在凌晨吃外卖，管不住嘴，吃撑了胃。我不知道发生了什么，也不知道自己正在经历什么。不过我也观察到，无论多晚睡觉，我总是在八点左右起床吃早餐，而且从来都没有超过九点钟，好像起床时间跟定死了一样，雷打不动。

破局：寻找属于自己的“参考对象”

在家住了半年之后，我去我姐姐家帮忙照顾小孩了。离开父母以后，我感到久违的轻松与平静，脑袋也没那么昏沉了。姐夫对我说，既然对编程有兴趣，那就试着写一个小工具。我决定从 Python 开始。在姐姐家的半年时间里，我一边照顾小孩，一边啃廖雪峰 Python 教程，还时不时回顾我的成长经历。

老实说，照顾小孩真不容易。起初我觉得很累，因为他不怎么听话，后来我观察到，他需要的从来不是我以为的“听话”，而是一个能够读懂他情绪和行为的玩伴——在玩的过程中帮助他建立起对身边人事物最基本的感知，包括边界感和秩序感。在陪伴他的过程中，我意外照见了小时候的自己。有一次出门后他忘记带东西，我竟然吼了他一声：“你早干什么去了？”这句话一出口，我立刻呆住了，这个场景太熟悉了，我不就是这么长大的吗？他说：“嗯？你刚才说了什么？我没听见。”我说：“没什么，是我出门时忘了提醒你再仔细检查一下。”他说：“没关系。”那一刻我感觉心里有什么东西融化了。这半年里，是他治愈了我，让我看清了心里的阴影。

对于廖雪峰 Python 教程，我觉得还是太难，不够小白。没有编程基础、缺乏概念认知、不知如何确立学习目标，这让我屡屡受挫。我开始反思，我是不是在用一种“表演式学习”来制造“自己有在努力”的幻觉，以此麻痹痛苦？后来我发现，让我害怕和焦虑的，是不确定性。我开始意识到，人类社会里没有什么是绝对确定的，就连我中午吃什么，也会纠结一会。我开始冷静下来，反思以前的学习方法，发现一个问题：在缺乏基础知识的情况下硬啃一道练习题，浪费了很多时间，拖慢了整体进度。看似努力，实则无知和愚蠢。当我直接看答案，吃透了解题思路并独立完成它，我才真正学会了。我想起数学老师说过一句话：“抄答案不是目的，是学习的一种手段”，深以为然。

沉淀：那些看似毫无产出的日子

2026 年 5 月，学习遇到瓶颈，思路困顿，我连续打了二十几天游戏。当我再一次面对问题，开始有了思路，文思泉涌，顺流而下，把笔记补充完整了，这让我我非常开心。7 月又连续打了几天游戏，还经常出门散步，回来后很轻松地解决了问题。其实我会怀疑自己是不是在浪费时间，但事实证明，我在游戏和散步的同时，大脑在后台处理信息。不死磕，好好放松，好好休息，也是学习的重要组成部分。那些没有产出的一天又一天，其实是在为下一次的爆发积攒能量。

时至今日，已经有许多相似的经历证明了，在遇到一个想不通、没有思路的问题时，最舒服、最有效率的做法就是不死磕、不硬想、好好休息、好好放松。不要把注意力过度集中到问题的局部上，这样会让视野变小，忽略整体。把注意力放到散步和游戏上，让大脑在后台处理信息，休息一天，再回头看困扰我的问题，果然看到之前看不到的细节。找到了这个细节之后，思路就通了，问题也就解决了。

构建：世界是动态的，人也是

聊聊我的学习风格。我是高敏感（HSP）人格，具有强烈的完美主义倾向，总想着一次性把事情做好——比如我要实现某个功能，在实现过程中不由自主陷入抠细节的状态。虽然细节做好了，但对整体功能来说无关紧要。再比如写作，我经常边写边改，这也无意间增加了写作摩擦，改也不是，不该也不是，消耗更多能量，写完了也不开心。

这些教训告诉我：完美主义害人不浅，切忌因小失大拖慢整体进度。解决方案是：实现功能时，先确定框架，再划分模块，最后模块化执行。在执行过程中，从单个模块开始，粗糙的逻辑只要能跑就行，给其他模块预留接口之后立刻去执行下一个模块，等所有模块写完后再整体微调，然后深入细节并精修逻辑。大致流程为：功能 → 框架 → 模块 → 能跑 → 细节。

对于写作，同样是按照“先立骨架，再填血肉”的原则，确定大致的时间范围和事情经过，从中提炼主题，然后按照时间顺序+事情节点的方式划分成好几个小标题，骨架也就建立起来了，接着填充内容即可。填充内容的过程中不必按照时间顺序，而是哪个最有感觉就先写哪个，然后放开地写，不要有任何顾忌。把想写的内容完整填入各个小标题，先搞定初稿，先完成，再完美。大致流程为：主题 → 标题 → 填充 → 初稿 → 改稿。

不要一个劲在脑海里想，实际却没有采取任何可见的行为，这是写作大忌，会让人焦虑。初稿写完后，再慢慢抠细节，这样就不会因为写不出内容而焦虑了。但你也会因为改稿，删掉大段内容而感到不舍，这也是正常的。你必须学会取舍，而不能只会一厢情愿地写稿。

对于高敏感人群，首要任务是稳住情绪，其次是搞定事情。你会发现，你比你想象的还要强大。

在实践“问题导向”学习法时，我发现自己的思考在疯狂发散，从一个问题发散出多个问题，从单链到一张网，但实际行动却只能像单链表一样，一步一步往下走，这一度让我非常内耗。后来我意识到，思考时可以任由网状发散，但执行时必须收敛成一条单链，因为思考和执行分别对应两套不同的规则。遇到 Bug，先挑最核心的那个节点去查，搞定它，再顺藤摸瓜。不要试图在脑子里同时跑十几条链，否则大脑会过热宕机。

出关：带着真诚，走向真实的暴风雨

一想到要找工作，我便感到焦虑和胆怯，我既不知道能否胜任，也不知道会遇到什么样的人和事。不过我准备了那么久，笔记几乎填满了两个大大的笔记本，还搭建了个人博客，总归是有拿得出手的作品和值得讲述的故事。

我决定以真实的态度写简历，以真诚的态度沟通。我具备独立开发博客的经验，熟悉 Python/HTML/CSS 和开发者工具。经过对前端与 Python 后端行业需求的调查，我为自己划定了学习路径。现在，我正在深入学习 MySQL、Flask 与 JS，并且成功跑通了后端的第一个最小可执行接口。

我忐忑不安地打开招聘软件，查看岗位 JD，如果符合需求，我就会鼓起勇气打招呼。虽然我仍然会犹豫，会发怵，需要做心理建设，但我想到课题分离这个概念——是否选择打招呼，这是我的事；对方是否回应，这是对方的事；我只需要做好我的那部分就够了。打完招呼后，我感到非常轻松。接下来，我将持续深入学习，打磨本领，完善博客，写技术文章。同时我也会不断往外走，跟外界保持联系，在跟现实世界的交流中实现能量和信息的内外双循环。

如果你也是一名正在迷茫的转行者，希望我的经历能为你带来一点微光。愿你成为自己的光。
